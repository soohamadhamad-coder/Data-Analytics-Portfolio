Sales Analysis & Data Modeling Project

Project Overview

This project focuses on analyzing sales and order data using Power BI to transform business data into meaningful insights through interactive dashboards and structured data modeling.

The project covers sales performance, order activity, territories, order status, time-based trends, and product categories, followed by the development of a structured Star Schema for analytical reporting.

Project Objectives

- Analyze overall sales and order performance.
- Identify trends across time and territories.
- Analyze order status and product categories.
- Build interactive Power BI dashboards.
- Develop a structured Star Schema for data analysis.
- Apply data modeling and visualization techniques to support business insights.

Skills Demonstrated

- Power BI
- DAX
- Data Visualization
- Data Modeling
- Star Schema
- Business Intelligence
- Analytical Reporting

Project Structure

Phase 1 — Sales Overview

Initial analysis of sales and order performance using key performance indicators and interactive visualizations.

Phase 2 — Detailed Analysis

Expanded analysis using additional tables and visualizations to provide deeper insights into the data.

Phase 3 — Additional Dashboard Analysis

Added further analytical views to explore the data from different perspectives.

Phase 4 — Data Modeling

Designed a Star Schema to organize the data into fact and dimension tables and create a structure suitable for analytical reporting.

Phase 5 — Excel-Based Data Modeling

Applied the Star Schema concept to data prepared from Excel by organizing tables and removing unnecessary or repeated columns.
